### 🚀 Recording Tips:
1. **Start Local:** Run `bash demo.sh` to get the server running.
2. **Launch Tour:** Open `http://localhost:3000/?demo=true`.
3. **Capture:** Use Loom (1080p+) or OBS. Zoom in on the AI Co-Pilot chat and the NFT morphs.
4. **Energy:** Keep the tone upbeat. If you mess up, just pause and restart the sentence; you can edit it later in CapCut.
